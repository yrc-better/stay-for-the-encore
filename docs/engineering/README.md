## 当前阶段重点

阶段 0 的目标是稳定现有 MVP 基线，确保测试、类型检查和构建通过，坏存档能回到开局并给出明确提示，主界面不暴露调试性质的结局预览入口。

阶段 1 正在收口校园序章，包括随机事件抽取、出身路线事件、固定毕业演出锚点、毕业资源继承，以及从毕业演出结算进入正式生涯的流程。
