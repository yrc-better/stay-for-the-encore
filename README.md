# 乐队模拟器

一款桌面端优先、可以完整游玩二十年生涯的单机文字经营网页游戏。玩家从大学毕业开始，以队长、吉他手兼主唱的身份组建固定五人乐队，通过每月三个行动点经营成员成长、作品、舞台、公共资金与彼此关系。

## v1.0 完整内容

- 四种整局锁定风格：流行、独立摇滚、朋克、金属
- 十二名固定候选人和完整五人组队、命名流程
- 每月三个共享行动点、个人行动与乐队行动
- 成员永久属性、临时状态、归属感、关系危机与财务危机
- 专辑创作、编曲、录音、发行、质量、收听和收益
- 0 至 3 个持久化月度邀请、一级至五级场地、自主演出和现场履历
- 三类设备槽、四档设备、换装折价与隐藏判定修正
- 四类商业合作、独立发行、小型厂牌与大型唱片公司合约
- 60 个以上数据化事件、风格内容、成员专属故事和跨月事件链
- 二十周年、成员决裂、债务解散、主动结束和特殊故事结局
- 结局称号、代表专辑、关键演出、五名成员结语与精选时间线
- 本地单存档、v1 至 v2 自动迁移、损坏保护、导入、导出和清除

游戏不设唯一胜利条件。一局可以走向商业巨星、地下传奇、现场之王、技术标杆、创作名团、长青乐队等不同总结。

## 本地运行

需要 Node.js 22 和 npm 10 或更高版本。

```bash
npm install
npm run dev
```

开发服务器会在终端显示本地地址。

## 质量检查

```bash
npm run check
git diff --check
```

`npm run check` 会依次执行 TypeScript 类型检查、全部 Vitest 测试和生产构建。领域层另有多随机种子的 240 个月长局模拟，用于检查流程死锁、数值越界和结局触发。

## 存档与回滚

- 存档只保存在当前浏览器，不使用账号或云端同步。
- 首页可以导出 JSON 备份，也可以导入或清除存档。
- v1 存档首次载入时会迁移为 v2，并在覆盖前保留备份键。
- 若新版本出现兼容问题，可重新部署上一份已验证的静态构建；玩家导出的 JSON 仍可用于恢复。
